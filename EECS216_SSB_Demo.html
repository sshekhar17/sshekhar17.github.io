Start from suppressed-carrier AM, remove one sideband, and compare coherent reception. SSB uses half the RF bandwidth, but a receiver phase error can both reduce the component matching the original signal and distort its waveform.

Things to try and observe

Begin with Two tones or Pulse test.

  • Save bandwidth: Compare DSB-SC with Upper and Lower SSB. Observe which half of each RF band disappears.
  • Correct receiver: Set φ = 0° and noise = 0%. The recovered audio closely matches the original.
  • Phase-error experiment: Raise φ to 45°, then 90°. DSB-SC fades; SSB retains output power but changes the waveform.
  • Compare waveforms: Watch the three aligned plots and listen to DSB vs. SSB recovery. Turn on noise or change the LPF cutoff afterward.
